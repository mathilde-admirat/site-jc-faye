# Site de Jean-Christophe Faye — maquettes

Psychologue clinicien, psychanalyste jungien (Clermont-Ferrand · Aydat).
Trois propositions de style pour le futur site, avec le même contenu.

| Fichier | Style |
|---|---|
| `index.html` | Page d'accueil qui présente les 3 maquettes |
| `1-chaleureux.html` | Chaleureux & symbolique : bleu nuit, ocre, mandala |
| `2-litteraire-bleu-or.html` | Littéraire : papier, bleu nuit et or, gravures alchimiques |
| `3-litteraire-ocre.html` | Littéraire : jaune paille, ocre, brun |

## Voir les maquettes

- En local : ouvrir `index.html` dans un navigateur.
- En ligne : via GitHub Pages (Settings → Pages → branche `main`, dossier `/ (root)`).

## À savoir

- Chaque page est autonome (HTML, CSS et JavaScript dans un seul fichier). Seules les polices viennent de Google Fonts.
- Le module de réservation est une **démonstration** : les créneaux sont fictifs et générés automatiquement. Il faudra le relier à un vrai outil d'agenda (Doctolib, Calendly…).
- Restent à fournir : photo, tarifs, mentions légales.
- Illustrations : dessins « d'après » des gravures alchimiques du domaine public (Maier, *Atalanta fugiens*, 1617 ; *Rosarium philosophorum*, 1550 ; *Chrysopée de Cléopâtre*).
